## Featured Projects

### 1. Digi-Timeline
[View Repository](https://github.com/aditigupta-dot/Digi-timeline)

A unified academic and productivity dashboard that brings activity from GitHub, Gmail, Google Calendar, and Google Classroom into one timeline. Includes synchronization, tasks, analytics, notifications, and an assistant grounded in imported records.

**Tech:** Java 21, Spring Boot, Spring Security, JWT, JDBC, PostgreSQL, Flyway, React, Vite

### 2. Subway Runner AI
[View Repository](https://github.com/aditigupta-dot/subway-runner-ai) | [Play Game](https://subway-runner-ai.vercel.app/)

An interactive 3D endless-runner game with a voice assistant that responds to the player and triggers in-game actions.

**Tech:** React, Vite, Three.js, React Three Fiber, Node.js, Express

### 3. Lost in Random
[View Repository](https://github.com/aditigupta-dot/lost-in-random)

A quantum-themed browser game featuring 8 themed worlds, additional randomized game modes, player accounts, persistent progress, and leaderboards.

**Tech:** HTML, CSS, JavaScript, Node.js, Express, MongoDB, JWT

### 4. Quantum Edge
[View Repository](https://github.com/aditigupta-dot/Quantum-Edge)

An exploration of quantum computing for portfolio optimization. Models asset selection as a QUBO problem and experiments with the Quantum Approximate Optimization Algorithm (QAOA).

**Tech:** Python, Qiskit, NumPy, Pandas

### 5. DSA C Programs
[View Repository](https://github.com/aditigupta-dot/dsa-c-programs)

A category-based collection of 29 standalone C programs covering sorting, searching, recursion, greedy algorithms, dynamic programming, graphs, and backtracking.

**Tech:** C, Data Structures & Algorithms, HTML, CSS, JavaScript
